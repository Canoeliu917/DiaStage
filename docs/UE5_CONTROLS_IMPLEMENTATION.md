# DiaStage：UE5 主布局、中键环绕与置景资产接入

## 最终要求与完成边界

以 **UE5.6、Windows、普通三键鼠标、关卡编辑器**为主规范。用户随后要求加入 Blender 中“按住滚轮拖动”的环绕效果，因此增加这一明确的观察扩展。此前 Q/E 左右环视和 Ctrl 旋转要求仍已撤销。产品应标为“UE5 主布局＋中键环绕”，不能宣称完全原版 UE5。

本次交付用户指南、应用内帮助及中键观察的运行时代码；其余 UE5 输入处理尚未改造。中键扩展已在修改分支实现，完整 UE5 布局仍按本文继续实施。源码核对基线为 `4170d1919a8eb25a7bc96503dfb55098b71bbbfe`，开工时重新核对当前分支差异。

## 已实现的中键扩展

三维视口中，中键拖动环绕当前观察中心，Shift+中键与 Alt+中键在观察平面内平移；滚轮保持原有透视推拉 / 正交缩放。二维平面图和第一人称入口分别使用自己的控制情境。修改位于 custom-camera-controls.tsx 的既有输入配置内。

指针按下时读取事件中的修饰键，防止从窗口外按住 Shift 后进入画布时错误环绕；失焦取消拖动并清理修饰键。中键的浏览器自动滚屏已阻止。相机移动不写入道具变换。

以相同锁定版本 camera-controls 3.1.2 和 Three.js 0.185.0，在 jsdom 中执行真实输入 effect，核对透视 / 正交的环绕、平面平移、窗口外修饰键、失焦取消及画布外事件。未运行完整应用的浏览器端测试。

## 现有冲突必须一并迁移

- 当前 V 选择迁移为 Q；V 在移动工具中用于顶点吸附。
- 当前 E 门窗交互、R/T 步进旋转迁出关卡编辑通用键位。门窗、柜门和抽屉使用部件属性或可见交互入口；E 旋转，R 缩放。
- 当前 Ctrl+右键及 Ctrl+Shift+右键直接旋转不再作为默认手势。旋转统一经 E 的操纵器，连续 / 离散角度由旋转吸附设置控制。
- 当前普通视口 WASD 平移、右键环绕按透视与正交上下文迁移。右键飞行导航优先于 Q/W/E/R/F 工具命令，释放右键后恢复工具语义。
- F 切布置图层、空格配左键平移、轻按 Ctrl 切网格步长迁回对应菜单或工具栏，不再抢占标准命令。
- 当前 Ctrl+Shift+G 取消编组改为 Shift+G；Ctrl+Shift+G 控制组选择。组关系进入项目保存和历史，不仅保存在会话。
- 第一人称排演、网格建模、文字输入保持各自上下文。编辑命令不得在输入框或演出播放中误触发；第一人称监听器也不能抢走关卡编辑命令。

## 实施约束

1. 完整阅读 AGENTS.md 和相关架构文档。修改选择前阅读 selection-managers、scene-registry、events；修改移动 / 放置前阅读 tools，落实二维与三维行为一致。
2. 沿用既有输入与控制结构。重点核对 `packages/editor/src/hooks/use-keyboard.ts`、`custom-camera-controls.tsx`、`first-person-controls.tsx`、`direct-manipulation.ts` 及节点变换工具。core 不引入 Three.js，viewer 不依赖编辑模式。
3. 统一事件优先级：正在输入或弹窗捕获 → 当前拖动 / 专用工具 → 当前视口导航 → 关卡编辑命令。无修饰字母命令不响应 Ctrl/Alt 组合的尾键。命中控制柄时不启动相机操作。
4. 通用道具补齐 XYZ 平移、三轴旋转、缩放、世界 / 局部空间及数值输入。多选与组变换使用明确支点，避免各节点不同步。
5. UE5 界面按 X 前、Y 右、Z 上、厘米和角度解释。当前底层是 Y 向上和米制，使用明确的坐标 / 单位适配层，不直接重解释已保存的位置与旋转。旋转通过基变换矩阵或四元数转换，不能简单交换欧拉角；核对左右手、法线、镜像及非均匀缩放。
6. 位置、旋转、缩放吸附分别设置开关与增量。End 和拖动贴面使用场景表面查询；法线对齐与表面偏移独立设置，排除道具自身。
7. 沿用命令与历史体系：拖动连续预览，松开提交一次事务，取消则还原。复制拖动包含创建与变换，撤销整体回退；重做保留副本身份。
8. 指针取消、失焦、切视图、删除选择和工具退出时清理输入与临时状态。相机按帧间隔更新，松键即停。
9. 工具栏、指南、菜单、提示、二维和三维保持一致。触屏提供可见工具和控制柄，调用相同命令。
10. 按实际完成情况更新指南的适配状态，不以文本修改代替功能验证。

## 置景资产接入

模型包有 22 个 GLB、catalog.json、diastage_manifest.json、可编辑几何与 Blender 构建脚本，以及新编的 9×7 m 排演组合示例。

- 六类：空间围合、门窗、台块与支撑、沙发、桌、椅凳。20 类基础道具加二帘、三帘组合；不同朝向不重复登记，圆桌椭圆示意不新增为椭圆桌。
- 米制 1:1；PPT 的 1:40 是示意比例，不再次乘除 40。GLB 为 glTF 标准 Y 向上，catalog 原始 bounds 和示例坐标为 Blender Z 向上，避免重复转换。
- 保留稳定资产 ID；每次放置生成独立实例 ID，保存 position、rotation、scale、部件 controls。实例转向不得修改共享几何。
- 名称、缩略图、占地、来源页码、明确尺寸与假定尺寸分别呈现。高度待实测不得呈现为已测量。
- 门扇、抽屉、景片铰链保留独立节点。家具以落地中心定位，折叠景片以首片左端地面支点定位，见 catalog.pivot。部件支点与整体支点分开处理。
- 门窗利用框架或开口信息建立碰撞 / 导航，不用整块包围盒封死门洞。collision_hint 只是接入提示，尚未实现物理或通行判定。
- 排演示例不是 PPT 第 3 页的坐标复原，9×7 m 为假定。其他未给定的高度、厚度、材质与构造已注明。
- Blender 脚本生成新场景和带时间戳的工程。当前环境未执行 Blender，仅完成脚本语法检查；GLB 已实际生成并独立重导入验证。

## 验收

中键部分已有针对性验证；其余条目仍是完整 UE5 适配的验收要求。

| 情境 | 预期结果 |
| --- | --- |
| 三维中键环绕，Shift / Alt+中键平移 | 道具变换不变；环绕时观察中心不动，平移时视线方向不变 |
| 中键拖动时失焦再返回 | 旧拖动停止，无粘住的 Shift / Alt 状态 |
| 松开右键，Q/W/E/R 与空格 | 工具符合标准，切换工具不改道具变换 |
| 右键 + Q/E、WASD、R/F | 只导航相机，不旋转道具、不触发开门或图层切换 |
| F 聚焦、Alt+左键环绕 | 正确选择中心，道具变换保持 |
| 输入、弹窗、失焦后返回 | 无误操作、残留按键或持续飞行 |
| 100 cm 方块世界 Z 转 45°、Y 转 30° | 水平转向与倾斜正确，轴色、数值、视觉一致 |
| 世界 / 局部切换，非均匀缩放物体旋转 | 方向符合选定空间，保存往返无镜像或轴交换 |
| 底边支点倾斜，End 贴面 | 支点、网格、表面关系正确，不吸附自身 |
| 三种吸附独立开关 | 一项开关不隐式修改其他项 |
| Alt+拖轴复制，撤销 / 重做 | 创建与变换为一次历史动作，实例身份稳定 |
| Ctrl+G、Shift+G、Ctrl+Shift+G | 编组、解组、组选择分别生效，组关系保存恢复 |
| 二维 / 三维编辑同一物体 | 投影适用的变换行为和保存数据一致 |
| 载入一号台块、圆桌、单门，保存重开 | 核对 1.80×0.90×0.15 m、直径 0.90 m、门口净宽 0.75 m；部件状态保留 |
| 网页 F11 / Ctrl+R 与界面入口 | 记录实际可用性，不将浏览器行为误报为功能完成 |

完成后报告修改文件、运行时实际支持的操作、验证结果和剩余差异。AI 提供排演与资产辅助，导演和演员保留选择权。
