## 仍需实际环境验收

- 腾讯云新目录构建与持久化验收：不上传 Windows `.next` 或原生依赖；不改旧服务目录。
- 实际证书、反向代理、防火墙和续期；健康接口必须能识别候选版本。
- 两个普通账号交叉读取/写入拒绝，登录退出、保存与重启留存；使用隔离数据库和临时场景。
- 真实浏览器的额度显示、未受邀提示、超额提示及手动置景可用；模拟调用结果不代替真实 AI 验收。
- 本机服务的自动启动曾被自动审批拒绝，未给出具体理由。本轮不更换工具绕过；用户手动启动后再补浏览器验收。启动时沿用原数据路径，避免意外进入空账号库。
