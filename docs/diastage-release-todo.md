## 已批准的 AI 内测额度与启用步骤

首轮最多 20 个受邀账号（管理员若使用付费 AI 也占一个名额），用户无需个人 API Key；服务器使用运营者的 `OPENAI_API_KEY`。额度固定为全站 100 元/月、账号 1 元/日及 5 元/月，所有剧目共用账号额度，单次请求内多轮模型调用另受 1 元任务上限约束。北京自然日/自然月重置；每日额度不会叠加到月额度之上。不新增支付、自动充值或包月扣款。

启用前由运营者核对申请人的身份与注册账号，将真实用户 ID 写入服务器私有环境的 `DIASTAGE_AI_BETA_USER_IDS`，用英文逗号分隔，最多 20 个不同 ID。不填则所有付费 AI 关闭；注册不会自动获得名额。不能填写邮箱、共享 token 或前端传来的 ownerId。可由本人登录后在 `/api/auth/get-session` 确认自己的 `user.id`，运营者应通过受信任渠道核对后批准；不要索要或传递登录 cookie、密码或 API Key。白名单变更需在获准的服务重启窗口生效。本轮不改真实白名单。

新账本按服务器登录会话的 userId 归属。SQLite 事务同时检查个人日/月、全站月及任务额度，先预留再调用；已知用量按内部价格表结算，失败且没有可靠用量时保留预留。超额停止新调用；手动置景、本地解析和保存不受 AI 额度影响。旧账本原行保留，无账号的旧费用仍计入原月份的全站用量，不分配给新用户。`DIASTAGE_AI_MONTHLY_USER_LIMIT_CNY` 旧配置不再使用。

“查看我的 AI 额度”仅显示当前账号数据，管理员额外看到全站汇总。不增加自动邮件告警、支付幂等接口或任务队列；现有 IP 限速、60 秒超时和 SDK 零自动重试保留。解析结果验证失败时已有的有限重试仍逐次预算，用户主动重试也会重新计入。设备联动保持默认关闭，缺少账号归属的远程转写不能调用付费模型。

金额是按项目参考价格和参考汇率统计的应用额度，包含在途预留，并非供应商最终账单。当前参考价标记 2026-09-10；公开启用前必须核对真实可用模型、价格、汇率、服务器网络和供应商账单。成功调用的用量若超过预留仍如实记录，不截断费用；后续请求会被限额阻断。

2026-10-25 已核对官方 Luna 基础价和转写价；本轮补上缓存写入计价（读取、30 分钟写入、12 小时写入分开统计），缺少写入细分时对未缓存输入使用默认写入价保守估算。另修复 AAC-LC 容器时间戳少报导致的语音时长与预算绕过，AAC 非 LC 编码暂不接受。

## 成本算例：非实测次数或消费承诺

参考汇率暂按 USD 1 = CNY 7，不代表实时汇率。文字算例假设所有输入按默认 30 分钟缓存写入价预算，实际有命中读取缓存时可更低；输出包含模型实际计费的输出 token。

| 用途与假设 | 单次估算（元） | 1 元理论次数 | 5 元理论次数 |
| --- | ---: | ---: | ---: |
| 文字请求：3,000 输入 + 800 输出 token | 0.01197 | 83 | 417 |
| 较大方案：10,000 输入 + 4,000 输出 token | 0.05110 | 19 | 97 |
| 30 秒语音转写，不含后续模型理解 | 0.01575 | 63 | 317 |
| 当前照片请求示例：11,319 输入预算单位（含图片高细节上界）+ 6,000 最大输出 | 0.07020825 | 14 | 71 |

照片行是本地请求结构的预留估算，照片名称、目录、模型或提示变化会影响它，结算通常因实际输出量变化。每个调用需先预留当前最大输出预算，因此快到限额时可能比按实际均价相除更早停止。一个剧目可包含多次调用；例如一次照片分析加十次上述文字请求，约 0.19 元，不能承诺任意完整场景都是此价。照片复原指现有资产生成可编辑舞台方案，不含额外外部 3D 网格生成服务。
