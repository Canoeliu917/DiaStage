# DiaStage 舞台布景拼接与空间规则

研究日期：2026-10-27。资产初核基线：`d6b0c6a7f93c459e0e7fa6a8dfae869fad94cda7`；折叠景片默认外框已按本轮真实 GLB 关节计算、catalog 与 `stageFoldGeometry` 修正。本文作为规则依据，不代表以下全部规则已进入运行时。

目标是用现有 21 件布景资产提出能修改、能检查的舞台布置预览。用户明确的默认约定是：**“房屋式／三面围合”保留后墙与两侧，开口朝向观众。** 这是 DiaStage 的产品语义，不是建筑规范，也不表示必须生成屋顶、第四面墙或真实住宅结构。

## 把几何规则写清楚

1. **拼接对象明确。** “贴着／拼成墙／三面围起来”需要指定接触的边、面、关节和内外侧。共面连续拼墙与转角拼墙不是同一种约束；角点不能靠互相穿进板厚解决。
2. **接触与穿透分开。** 两实体可在指定边界接触，但内部不能有超过数值容差的相交。沿目标拼接面法线的缝隙为零只是条件之一，还要有正确的横向／高度对齐；仅顶点碰到不等于整条接缝闭合。容差应由模型尺度和测试确定，本研究不规定通用毫米数。
3. **通道与接缝分开。** 只有明确相连的接缝追求零缝；门前、家具使用侧、演员走位保留所需净空。“靠近”不能自动变成“贴合”，“靠墙”不能把门洞一起堵住。
4. **粗判与实体分开。** 整体 AABB 适合快速排除远处物件；围合景片的空腔、门窗净洞、桌椅腿间空隙不能直接视为实心。精判应按可信的实体部件／几何进行；细节不足时明确是保守代理和待确认，不宣称真实网格精确。
5. **终点与路径分开。** 移动时需要 swept collision；铰接和门扇旋转检查完整扫掠。采样检查若有漏过薄板的可能，应标出其局限，不能把有限采样叫连续碰撞证明。
6. **支承与承载分开。** 检查底部接触位置和承托范围，可以发现明显悬空或穿透；只在侧边相切不提供竖向承托。缺少接触点／材料／质量／重心信息时，不判断结构稳定或允许上人。家具套入桌下的可能性也需真实局部几何和高度，而非单凭外框相交判定。

## Dia 的理解边界与验收对照

按仓库 `dia-language-trainer` 的“区分意图、保留歧义、只提案不自动执行”原则，以下是应进入相应实现／评测的验收要求，**本文件不声称已运行或全部通过**。

| 输入与上下文 | 应得到的语义／检查 | 不能混同的近邻情形 |
| --- | --- | --- |
| “用三联围成三面，开口朝观众” | 识别 3 片及 2 关节，结合舞台观众方向构造 U 形；检查真实片体与接缝。 | 不是复制三件三联，也不是封闭四壁房屋。 |
| “用二联拼后墙和两侧，像房间一样” | 结合所需长度提出足够组合，保留前方开口；数量或尺寸不足要说明。 | 二联是两片，不等于现有一件便足够任何房间。 |
| “这两块台块拼齐，缝不要留” | 目标侧面贴合、顶面齐平，允许接触而不允许穿透。 | 不能把全部家具间隙吸到零，不能将两台块中心重合。 |
| “沙发靠近窗景片，留出走人的地方” | 接近与留通道同时保留；净距未知时确认用途／尺寸。 | “靠近”不是“接触”；窗洞不是默认通道。 |
| “把椅子挪到门后” | 检查净洞、开门方向和门扇活动区；若阻碍开门需说明或换位预览。 | 门框总宽不能代替门扇扫掠，也不能把门洞当整块实墙。 |
| “这块方墩垫在大台块下面就能站人吧” | 可给几何预览与承托待核提示，拒绝凭模型保证上人承载。 | 零碰撞／接触地面不等于结构安全。 |
| “三面围起来”但未载入舞台朝向 | 观众方向有已知上下文时沿用；未知时询问开口朝向。 | 不根据当前相机随意改变房间开口。 |
| “挪过去就行，起点和终点都没碰到”但中途隔着景片 | 识别为路径问题，检查移动途中；不能直接越过障碍。 | 终点不碰撞不等于路径可行。 |
