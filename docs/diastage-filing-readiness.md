# DiaStage 备案后上线准备

核对日期：2026-10-22。适用域名：`diastage.art`。本次修改基于分支 `codex/private-scene-accounts-v01-20261014`，提交 `d8c495a`。

已核对服务器现有 Node + Nginx + systemd 部署，下一步具体操作见 [发布操作说明](diastage-production-deploy.md)。

## 已确认与已准备

- 腾讯云控制台显示网站“DiaStage咫台”已通过管局审核，主体与网站状态正常。
- 主体号：`粤ICP备2026162365号`；网站服务号：`粤ICP备2026162365号-1`。
- 首页底部显示主体号，链接到 `https://beian.miit.gov.cn/`，无需登录或点亮舞台即可查看。
- 广东应悬挂主体号，因此页脚不带 `-1`。备案号沿用网站字体，位于页脚右下方；适配首页明暗主题，并保留键盘焦点和手机可点击区域。
- 本地账户数据库、密钥及私有运行目录须排除在 Git 和 Docker 构建上下文之外。

这些是本地准备结果，尚不能据此确认公网网站已部署或公安备案已通过。

## 公网上线前

1. 在腾讯云核对 `diastage.art` 与 `www.diastage.art` 的解析、实际接入资源以及已备案的信息是否一致。控制台当前关联资源为 `106.53.215.79`；修改解析前应确认它仍是实际部署目标。
2. 配置两个域名的 HTTPS 访问；建议让 `www` 和 HTTP 入口重定向到 `https://diastage.art`，避免出现内容不同的首页。证书应覆盖两个域名。此前访问根域名 HTTPS 返回连接关闭，需在线上部署后复验。
3. 使用 Node.js 22.13 或更新版本运行服务，本地 Node.js 24.19.0 已完成生产构建。服务器现有 Node.js 22.22.1 的 SQLite 内存数据库及备份 API 探针通过。Bun 1.3.14 用于依赖安装和构建；本次沿用现有原生部署方式。
4. 在服务器私有环境中配置认证来源和密钥。以下是配置值说明，不包含真实密钥：

   ```dotenv
   BETTER_AUTH_URL=https://diastage.art
   MINT_PASCAL_HOST_ORIGIN=https://diastage.art
   ```

   `BETTER_AUTH_SECRET` 另行生成至少 32 字符的随机值，保存于服务器私有的 `/etc/diastage/production.env`，重启时保持一致。不得提交或将其写入公开客户端变量；公网来源缺少密钥时，现有认证逻辑会拒绝启动认证。
5. 持久化并备份场景与账户数据。沿用服务器现有 `PASCAL_DB_PATH=/home/ubuntu/diastage-data/scenes.db`；上线前核对数据库位置，避免启动出空库或覆盖原数据。本次只读核对为 0 条剧目，无需归属迁移；如发布前已有新剧目，参照 `SETUP.md` 的私有账户章节重新核对。
6. 核对公开内容及实际服务与已申报信息一致。当前账户邮箱验证、SMTP 和公开找回密码邮件尚未配置，见 `SETUP.md`；不能将这些能力描述为已具备。

HTTPS 是本版本公网账户认证的技术要求；本说明不将其表述为 ICP 备案本身的独立强制条件。

## 部署后的验收

- `https://diastage.art` 可直接打开，`https://www.diastage.art` 可到达同一首页。
- 未登录访问首页，滚动到底部可见 `粤ICP备2026162365号`；链接实际指向工信部备案系统首页。
- 首页明暗状态、桌面及手机宽度下，备案号可读、可点击，无水平溢出。
- 通过正式域名验证登录、退出和自己的剧目读取；不使用临时测试账户替代旧数据迁移核对。
- 服务器重启后场景和账户数据仍然存在；真实密钥、账户数据库和备份文件不出现在镜像、仓库或静态资源目录。

## 公安联网备案

腾讯云提示需在网站开通后 30 日内办理公安联网备案。控制台显示的同步数据码用于导入资料，不能作为公安备案号公开展示。

通过 [全国互联网安全管理服务平台](https://beian.mps.gov.cn/) 按真实信息办理。审核通过后，从该平台取得真实备案编号、图标和链接，再加入网站底部。本次不显示未经核实的公安编号或“公安备案已通过”标识。
