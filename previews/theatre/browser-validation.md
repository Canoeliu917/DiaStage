## 操作验收

| 操作 | 结果 |
| --- | --- |
| 置景 / 排演 / 复台切换 | 排演默认打开人物与行动，摄影机不作为默认入口 |
| 场地模板 | 宽深与自有地面真实同步 |
| 播放到终点 | 人物完成路径，终点停止 |
| 暂停 | 在 9.1 秒暂停，多次读取时间保持不变 |
| 键盘时间轴 | Home 后三次 PageUp 到 6 秒，显示送达行动及抵抗；道具按持有链预演 |
| 复位 | 时间回 0，恢复道具预置位置、解除本模块只读 |
| 平面图 | 显示本场圆桌、椅子、门、人物、标记与虚线路径 |
| 导演 / 观众 / 演员观察 | 可切换；二维转导演视角不再被旧导航插值覆盖 |
| 观众全景 | 按实际画幅取全舞台，平板不裁掉人物与门 |
| 面板分区 | 可用键盘 Home 调整上下区比例 |
| 手机 | 三工作区和更多菜单；工具抽屉可展开、收起；隐藏与当前戏剧任务无关的建模工具条 |
| 横向溢出 | 1440、768、390 宽度下 document.scrollWidth 均等于视口宽度 |
