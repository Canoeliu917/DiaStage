# DiaMotif

**DIA 系列最高层的知识、推理与训练评测体系。**

DiaMotif 是 DIA 的长期核心：将戏剧专业知识、语言理解、真实用户反馈与可复现评测汇集到同一入口，支持 DiaStage 及未来 DIA 产品。所有相关任务优先阅读这里，并把新证据和未解决问题写回这里。

## 强制收录边界：戏剧艺术与AI影视专业信息

自 2026-10-30 起，所有 DiaMotif 资料发现、候选收录、正式知识、检索结果、推荐、每日巡检和宣传位均遵守本规则。内容服务戏剧创作、表导演、舞美制作、艺考及AI影视创作人群；不建设泛娱乐资讯流。用户最新决定增加独立“AI影视”栏目，覆盖相关作品、创作技术、工具工作流及行业资料；这不解除八卦与私生活排除规则。

- **当前地域仅限中国大陆、香港、澳门：** 国外资料、国外网站及其他地区来源暂缓，不因外文资料价值而例外。大陆及港澳机构制作或引进的外国剧目，只收当地官方制作、演出与研究信息。既有国外资料留作研究档案，从公开资源检索和联网候选中排除；通用专业术语继续可查，区域外参考仅留历史出处名称和定位，不提供外链。机构地域须有原文证据，不靠域名后缀推断。
- **十一类，共用一个检索入口：** 剧本、戏剧知识、演出影像、AI影视、演职人员、剧场剧团、演出票讯、院校招生、招募招聘、艺考资讯、戏剧节与工作坊。前台收成八个主项，组合项按需展开，运行目录已有72个专业细分方向，不新增独立搜索引擎。“院校招生”收院校、专业、招生简章与录取要求；“艺考资讯”收戏剧相关统考、校考、报名、成绩与考试政策，优先考试院、教育主管部门及院校原公告，保留适用地区、年份、公告日期与更正。目标年份未公布明确留空，机构营销不能替代官方考试政策。
- **AI影视单列参与依据：** 作品分别标记AI生成、AI辅助制作、以AI为题材、使用情况待核验；技术文档、行业通知及研究综述标为AI创作资料，不把讨论AI的资料误当作AI题材作品或制作证明。普通影视内容不能只因发布者提到AI就入库。戏剧演职人员栏目仍须戏剧经历；AI影视人员的贡献先随其可核作品资料记录，不扩展私人履历。
- **戏剧节与工作坊：** 包括大小戏剧节、展演单元、编导演及舞美等专业工作坊和征集报名，保存主办方、届次、举办地区、时间地点、费用、公开报名入口、适用对象与截止状态；未公布项留空，过往届次或已截止活动只作历史资料，不当作当前可报名机会。
- **按资料本体严格分类：** 以[专业分类规则](references/search-classification.md)及既有145个概念、登记来源为依据，一条资料一个主分类，跨专业关联用主题保留。剧情与制作介绍不冒充剧本，角色公告不冒充人物档案，工作坊报名不冒充岗位招聘。联网发现尚未核验内容时分类留空，显示“分类待核验”，不按当前选择的分类自动贴标签。
- **戏剧知识内部细分：** 表演、导演、台词与声乐、剧作与构作、舞台美术、制作与管理、戏剧史论；保留全部知识。初始158条知识已逐项建立[方向映射](knowledge/search-knowledge-topics.json)，后续核验知识在资料的subtopics中显式登记，当前知识类178条。可有依据地交叉归类，未审资料仅进入全部知识，不以关键词或模型猜测自动归类。
- **明确禁止：娱乐新闻、花边新闻、演员八卦、绯闻、恋情或私生活炒作、狗仔爆料、饭圈争论、明星热搜及无戏剧专业关联的流量内容。** 不得因点击量、知名度、媒体转载或付费推广而放宽收录标准，也不得把传闻写成知识或验收题。
- **演员必须与戏剧强关联：** 资料应关联可核查的剧目、角色、演出版本、剧团、剧场或戏剧创作／教学经历。话剧、戏曲、歌剧、舞剧、音乐剧、沉浸式及其他戏剧演出的专业人员均可收录，不按名气或剧场大小筛选。影视从业者仅收其实际戏剧关联资料；新人可自愿提交专业资料，未经核实明确标记，不编造演出履历。不采集私人联系方式及其他非必要个人资料。
- **来源与事实必须可追溯：** 优先主办方、剧院／剧团、艺术院校、图书馆、出版社及研究机构原始资料；每条保存来源网址、作者或发布机构、版本／适用年份、发布日期、核验时间和证据定位。专业观点标明作者与流派，AI 推断和未核实线索不能冒充官方事实。来源不明、拼接截图、营销转载和搜索摘要不能单独成为事实依据。
- **混合内容不污染信息流：** 同页含专业信息及八卦时，只在可独立核验并准确引用的情况下保留专业事实；无法分离则整条拒收。演出变更公告只记录必要的演出状态，不扩展推测演员私生活。
- **允许大陆及港澳各地演出与票讯：** 覆盖话剧、戏曲、歌剧、舞剧、音乐剧、沉浸式戏剧、实验／物件／偶戏、儿童戏剧及其他相关舞台演出，也包括小剧场、独立剧团、校园和线上直播／录播。区分现场场次、线上播出和历史录像，不能把旧录像当作正在售票的演出。
- **票讯必需字段：** 剧名、演出类型、制作／演出版本、主办或出品方、剧场／线上平台、城市与场地、场次日期时间及时区、票价与币种（以原文为准）、官方售票入口或官方明确授权的渠道、预售／在售／售罄／改期／取消状态、最后核验时间及更正来源。未公布或不能实时确认的价格、余票、退改规则明确留空或标为待核验；不猜余票、不编造优惠、不收黄牛与未经核实的转售，不自动购票。
- **专业宣传单独标识：** 可收录真实剧目宣传、演员作品展示、剧目招募、戏剧艺考机构及课程；广告或合作须明确标识，不混入中立知识答案，不因投放影响来源核验和自然检索排序。机构收录不等于资质认证或推荐；招生、招募和演出信息按适用年份及截止状态更新。
- **访问与许可分开判断：** 能搜索、观看或订阅不等于允许转载、转录、下载或入库全文。许可未明确时仅保存书目／资源元数据、原始链接和允许范围内的自编摘要；原始用户 PDF 继续不云存，已采纳片段按既定私有素材规则处理。

此规则已同步到本聊天每天07:21及19:21（Asia/Shanghai）的早晚增量任务，每轮最多发现60个去重候选、优先核验20条；手动批次可按实际核验继续推进。当前公开索引248条：96条已核来源资料及书目、145个通用概念、7项来源登记，不能冒充248条行业资讯或独立作品。继首轮新增20条后，第二轮优先复审16条旧候选并主动扩充，共新增可检索41条，其中7条为经出版社核对的书目，并非教材全文。旧候选中8条直接通过，3份可信同题／相关替代资料另收，原链接仍保留未核状态。当前[待核队列](knowledge/pending-sources.json)分别保留6条原链接待核（其中2条已有同题替代）、4条访问受阻、3条拒收，不反复重做已收录或已拒收的来源。25条国外资源及区域外来源登记继续暂缓。联网准入覆盖区域机构与指定国内平台，域名符合不代表正文地区、账号身份、事实、时效或许可已核实；手动联网只显示候选元数据；统一智能搜索显示经引用校验的回答，联网候选仍不自动成为正式知识。本次没有启用全网任意爬虫、受限全文入库或公网部署；不能称为全网已收录。课堂展示、备课包及教师专用产品功能不在当前范围。

稳定增量资料入口为[domestic-discovery.json](knowledge/domestic-discovery.json)，来源发现与平台缺口见[工作流](references/discovery-workflow.md)。收录由Codex主动检索、读取、核验与分类，用户提供资料只是可选补充。自媒体、专业媒体、官方原始发布、观众评论与商业推广分别标记；没有读取原文或原站有效元数据的索引结果不能计作正式新增。新域名与新平台账号先核验准入，未完成时保留候选并继续其他渠道。

## 与运行中的 DIA 连接

下列代码是 DiaMotif 当前的运行实现，保持单一来源，不复制第二套知识或解析器：

- [知识目录](../apps/editor/lib/rehearsal-intelligence/knowledge/catalog.ts)：145 个概念、12 个登记来源；包括定义、别名、正反例、区别关系和证据级别。
- [知识检索](../apps/editor/lib/rehearsal-intelligence/knowledge/retrieval.ts)与[模型上下文](../apps/editor/lib/rehearsal-intelligence/knowledge/model-context.ts)：每次最多 6 项、8KB；省略资料时标记 `truncated`。
- [DIA统一对话入口](../apps/editor/lib/rehearsal-intelligence/dialogue-server.ts)：每条当前置景对话先提交千问，带入当前舞台、有限历史、待采用方案和实际检索知识；随后校验并预览。旧 [open-language-server](../apps/editor/lib/rehearsal-intelligence/open-language-server.ts) 保留作对照及兼容。
- [语言训练工作流](../.agents/skills/dia-language-trainer/SKILL.md)：从误解和人工纠正形成对比案例，修改规则，再复测。

当前是知识检索、提示上下文、规则与评测体系。尚未进行基底模型微调，也没有将全部教材正文导入模型；不能把“加入参考书目”写成“模型已经掌握全书”。

## 资料与反馈闭环

1. 登记来源：书籍／机构资料、用户原话、人工标注、模型输出、合成案例分别标记。
2. 核实与整理：保留版本、阅读范围、出处、必要上下文和不确定项。
3. 形成可用知识：明确词义、流派差异、正例、易混淆反例和应澄清的情况。
4. 验证：记录输入、预期、实际结果、错误类型、模型与规则版本、复测证据。
5. 人工审阅：经确认才加入固定评测集或未来训练候选；用于调整规则的样本不得再冒充独立验收样本。

未来所有用户语言实测、试验、内测结果和修正都沿用此流程。GitHub 收录脱敏且允许公开的案例及汇总；原始账号、联系方式、私有剧本、照片和密钥不随记录上传。`private/` 已被 Git 忽略。现有应用反馈仍留在其私有存储，本次没有启用后台自动采集或自动上传 GitHub。

## 当前产品原则

DiaStage 咫台是戏剧艺术 AI 平台，当前优先建设首页检索、知识问答与来源跳转；Dia 是对外的戏剧艺术 AI 检索引擎，DiaMotif 是内部知识与评测体系名称。舞台作为辅助工具，保留 AI 置景、照片置景、剧本置景与手动搭建的既有能力和数据，用现有 21 件标准道具作排练替代；尊重真实尺寸、贴合、碰撞和观众视角。正式场景变更仍由用户采用并通过确定性校验。手机、平板、投影、复台与语音保持既定暂缓范围。

“最高层”表示 DIA 系列共享的长期知识与评测优先级，不等于把所有研究方向立即开放成产品功能。
