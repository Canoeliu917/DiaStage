# Dia 检索专业分类

本规则依据用户2026-10-30的分类决定、DiaMotif已登记的基础戏剧资料及现有145个概念建立。参考入口为[书目与已读范围](theatre-books-and-sources.md)及[实际知识目录](../../apps/editor/lib/rehearsal-intelligence/knowledge/catalog.ts)；书目登记不表示已读全书，也不将某一流派观点作为唯一行业定论。

运行时分类名称和边界集中在[search catalog](../../apps/editor/lib/diamotif-search/catalog.ts)。联网提示直接读取该边界。前台七个导航组共用搜索框，原始十类保持独立，不因导航分组改变数据分类。

## 分类依据

按资料本体、发布目的和实际可访问内容确定一个主分类；作品名、人物名、话剧／戏曲／歌剧／舞剧／音乐剧／沉浸式等演出类型，及表演／导演／台词声乐／构作／舞美／舞台管理等专业属性保留为主题。不能只见“雷雨”“导演”或“招生”便自动归类。缺少正文或具体内容证据时保留候选，不能用所选标签替代分类核验。

- **剧本**：剧本文本、译本、选段及可定位版本的文本目录。剧情简介、小说原著、制作阐述和演出视频不算剧本。目录仅代表查找入口，不能声称已有全文。
- **戏剧知识**：术语、理论、表导演方法、人物行动与戏剧构作、台词声乐、舞美和舞台制作研究、历史与专业书目。保留出处、版本、流派和阅读范围。现有《雷雨》创排阐述、《骆驼祥子》舞美及《剧院魅影》制作公告属于知识，不冒充剧本或当期票讯。
- **演出影像**：可定位实际观看入口的舞台录像、选段、创作纪录、排练与专业访谈影像。区分全剧、片段、纪录和历史录像；纯文字报道、同名影视剧、娱乐采访和仅有音频的页面不能当作演出视频。
- **演职人员**：演员、导演、编剧、作曲、舞美、设计及制作等人员的可核实戏剧经历，关联作品、角色、职位、版本或教学经历。艺术家名录只是目录；一则卡司公告不等于完整人物档案，私生活不收录。
- **剧场剧团**：剧场空间、剧院机构、剧团及制作演出团体的基本与专业信息。机构介绍和场馆设施归本类；该机构某部作品的单场演出、票价和排期另归票讯。
- **演出票讯**：具体作品版本、城市、场地、场次、巡演和官方售票事项。现场、线上演出、历史录像分别核验；节展总览不直接当作一场售票演出，实时余票不推测。
- **院校招生**：院校与戏剧专业、学历项目、招生简章、申请和录取要求。香港演艺学院戏剧申请入口属于此类；目标年未公布不补写报名或录取条件。
- **艺考资讯**：教育主管部门、考试院及院校发布的戏剧相关统考、校考、考试报名、考试成绩和政策说明。必须区分适用地区、年份、公告阶段与更正；地方统考说明不能替代院校录取要求。
- **招募招聘**：发布主体明确的选角、试镜、演职岗位、剧组招募及剧院招聘。区分角色／岗位与用工或项目条件；课程招生、工作坊报名和付费培训不算就业机会。
- **戏剧节与工作坊**：大小戏剧节、节展单元、创作交流、专业工作坊及征集报名。保留主办方、届次、专业主题、时间地点、费用、适用对象和截止状态。节展内某场具体演出可另建票讯并关联节展，不能复制总目录充数；过往工作坊不是当前报名。

## 核验与收录

本阶段仅中国大陆、香港、澳门机构的相关信息与网站。通用专业概念继续可查，区域外历史参考不提供跳转链接；不扩展娱乐新闻、八卦与私生活。机构或地区匹配不证明页面正文、时效、内容地点和许可已经核实。

正式条目必须有明确主分类；联网发现的来源使用`category: null`和`web-candidate`，显示“分类待核验”。用户选择的分类只限制搜索意图，不把回传网页自动认定为该类。核验原文、专业关联和分类边界后才能正式收录，不能以模型猜测替代。

已有27条区域官方资源已做分类复核，未发现需要将同一条目改到其他主类的明显误分。剧本与招聘仍缺少本阶段可公开的正式资料，保留真实空状态；不能用国外来源、剧情简介、培训广告或泛招聘补足数量。
